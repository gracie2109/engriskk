# Skills

Skill thật nằm ở `.claude/skills/<tên>/SKILL.md` (Claude Code tự nạp). Thư mục này chỉ là mục lục để các agent biết dùng skill nào.

| Skill | Dùng khi | Agent |
|---|---|---|
| `commit` | tạo commit/nhánh/PR (Conventional Commits, tiếng Anh, không byline AI) | tất cả, devops |
| `orchestrate` | tác vụ nhiều bước | orchestrator |
| `authorized-incremental-execution` | làm liền theo kế hoạch đã duyệt trong phạm vi cho phép | tất cả |
| `personal-coding-standards` | viết/review code, quyết định có tách module không | tech-lead, frontend, backend, reviewer |
| `personal-supabase-standards` | **chưa áp dụng** (repo không dùng Supabase) | dba, backend khi có Supabase |
| `review-pr` | review diff/PR | frontend-reviewer, security |
| `static-web-frontend` | code web tĩnh JS thuần | frontend |
| `localstorage-data` | schema, sao lưu, di chuyển dữ liệu | backend, dba |
| `toeic-content` | soạn/soát câu hỏi, bài nghe, ngữ pháp | qc, dba |
| `vocab-srs` | từ vựng, lịch ôn 1/3/7/14/30 | backend, qc |
| `browser-qa` | kiểm thử Playwright | qa |
| `ui-a11y-ipad` | iPad, cảm ứng, truy cập | design, frontend |
| `ux-copy-vi` | chữ giao diện tiếng Việt | design |
| `deploy-pages` | GitHub Pages | devops |
